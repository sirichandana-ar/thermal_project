Control Strategy

Decision Logic
Predictive Auto

Uses the thermal-memory model to predict the temperature 60 minutes ahead.

Eco Hysteresis

Uses a wider ±1.5°C buffer to reduce unnecessary HVAC switching.

Strict Comfort

Uses a tighter ±0.5°C buffer for quicker response around the target.

Override

Uses the current room temperature directly instead of the predictive temperature.

What is hysteresis?

Hysteresis creates a small temperature buffer around the target so the HVAC does not repeatedly switch ON and OFF when the temperature is close to the threshold.
