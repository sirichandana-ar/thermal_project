4-Stage Pipeline Flow

software-only
1
Step 01 simulate_data.py / live_feed.py

Simulated Sensor Layer

Generates temperature, humidity, and occupancy readings. Temperature evolves from the previous temperature, allowing the simulation to represent thermal inertia instead of generating each reading independently.

2
Step 02 thermal_memory.db

SQLite Memory Store

Every sensor reading is timestamped and stored in SQLite. Before prediction, the recent readings are aligned to a consistent 15-minute model grid so temperature lags represent meaningful time intervals.

3
Step 03 train_model.py

Random Forest Regressor

The model learns from thermal-memory and context features including previous temperatures, rolling temperature averages, hour, day of week, occupancy, and occupancy trend.

10 MODEL FEATURES

temperature lags • rolling temperature • occupancy • time features

4
Step 04 app.py

60-Minute Predictive Decision

The model predicts four consecutive 15-minute temperature steps. These predictions form a 60-minute forecast, which is compared with the configured target temperature and passed to the selected HVAC control strategy.

Thermal Memory

core concept

The system does not treat each temperature reading as an isolated value. Recent temperature history becomes part of the next prediction through lag and rolling features.

EXAMPLE

Tnow → previous 15-min temperature → next prediction

This historical dependency is what gives the project its "thermal memory" behavior.
